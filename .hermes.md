# VizhMarket

Next.js app — Amazon product scraper & marketplace viewer.

## Stack
- **Next.js 16.2.9** (app router), **React 19.2.4**
- **JavaScript/JSX** — no TypeScript
- **Tailwind CSS v4** (`@tailwindcss/postcss`)
- **shadcn/ui v4** — components in `src/components/ui/`
- **Prisma 7** — PostgreSQL (`@prisma/adapter-pg`)
- **pnpm** — package manager
- **@tabler/icons-react** — icons
- **next-themes** — dark mode
- **@base-ui/react** — headless UI primitives

## Dev Commands
```bash
pnpm dev          # start dev server
pnpm build        # production build
pnpm start        # start production server
pnpm lint         # run eslint
pnpm postinstall  # prisma generate
```

## Project Structure
```
src/
├── app/
│   ├── actions/        # Server actions
│   ├── order/          # Order pages
│   ├── layout.js       # Root layout
│   ├── page.js         # Home page
│   └── globals.css     # Tailwind + global styles
├── components/
│   ├── Landing/        # Landing page components
│   ├── scraper/        # Amazon scraper (amazonScraper.js)
│   ├── theme/          # Theme provider + toggle
│   └── ui/             # shadcn/ui components
├── hooks/              # Custom hooks
└── lib/                # Utilities, prisma client, scraper helpers
prisma/
└── schema.prisma       # DB schema
```

## Conventions
- **JSX only** — `.js` and `.jsx` files, no `.ts`/`.tsx`
- Path alias: `@/*` maps to `./src/*` (e.g. `@/components/ui/button`)
- shadcn components in `src/components/ui/` — don't edit these manually
- Use `@tabler/icons-react` for icons over SVG or other icon libs
- Amazon scraper logic lives in `src/components/scraper/amazonScraper.js`
- Prisma client imported from `@/lib/prisma`
- Server actions in `src/app/actions/`
